# Risky Fitrawan - Portfolio Website

## Quick Start

1. Keep this folder structure:
   portfolio/
   ├── index.html
   ├── style.css
   ├── script.js
   └── assets/

2. Put your own files into `assets/` using these names:
   - profile.jpg       = professional profile photo
   - kai.jpg           = PT KAI internship photo
   - pmm.jpg           = PMM / Universitas Surabaya photo
   - project.jpg       = Vensim / thesis project screenshot
   - certificate-1.jpg = procurement certificate
   - certificate-2.jpg = Hadoop 101 certificate
   - cv.pdf            = your CV

3. Open `index.html` in Chrome/Edge.

## Important replacements

Search these placeholders in `index.html` and replace them:
- your.email@example.com
- linkedin.com/in/yourusername
- +62 800-0000-0000
- certification institution/year details

## Notes

The website uses Google Fonts when internet is available. The main layout, CSS, animations and image placeholders work locally.
